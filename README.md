# Jump!
Jump! is a simple website launcher. Enter a website’s name or address—such as example.com—to open it directly. It is designed for finding sites by name, not searching the web by topic.
Run locally

Save the project code as index.html.
Open index.html in a modern browser.
Enter a website address and select Jump.

# Features

Opens entered website addresses directly
Adds https:// when no protocol is provided
Shows example websites to try
Keeps a short list of recently visited addresses in browser localStorage
Works on mobile and desktop

# Notes
Jump! does not search or verify websites, and it does not endorse destinations. Check addresses before opening them. Recent history is stored locally in your browser.
